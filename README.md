# WEBTAP Edit Studio

Video-editing agency website with monochrome scroll interactions and an in-page, click-to-load Calendly scheduler.

## Run locally

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
```

The existing TanStack Start app, Vite configuration and Lovable connection are retained. Source for the new website is in `src/components/site/EditStudio.tsx` and `src/components/site/edit-studio.css`.

Booking calendar: https://calendly.com/hassansalehh753/30min

Note: This site is a reconstruction based on the requested WEBTAP Edit Studio design and does not contain the original private ChatGPT Sites project source.
